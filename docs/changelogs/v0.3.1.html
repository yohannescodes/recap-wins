Release v0.3.1

Released on June 28, 2026

✨ What's New

  • New commit comparison commands — rw draft, rw release-notes, and rw marketing generate content from any two commits, not just branch vs base
  • Flexible commit range syntax — Support both commit1 commit2 and commit1..commit2 syntax, working with tags, branches, SHAs
  • Full provider support — New commands work with all existing providers (Anthropic, Gemini, skill mode)

🔧 Changes

  • Documentation expanded with comprehensive examples for the new comparison commands
  • Homebrew formula updated to v0.3.1

📦 Installation

Update via Homebrew:

brew update && brew upgrade recap-wins
